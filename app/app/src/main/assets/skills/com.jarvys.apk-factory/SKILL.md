# APK Factory
Factory API26+, apps API24+. Inspect availability.
HTML/CSS/JS, not a fixed notes application. Preserve update identity/data formats.
## Contract
1. `apk_factory inspect`: check schema/capabilities/limits/template; actual results govern. Disclose unavailable.
2. Read scope version/files; relative paths only. Captain-reviewed adoption for external sources/attachments.
3. Clarify audience/workflows/style/identity/data/features. New apps: unique applicationIds/names/icons; updates: same appId/key, higher versionCode. Never replace unrelated apps.
4. Compare needs with inspect: web/spec cannot add code/libraries/permissions/services/APIs to precompiled DEX. Unsupported features require template review.
## Capabilities
Offline WebView only: no CDNs, remote fonts/scripts, API calls or login. Use accessible text/targets and loading/empty/error/recovery states.
Use responsive/scrollable forms and `<meta name="viewport" content="width=device-width, initial-scale=1">`. Native owns bar/cutout/keyboard insets; never subtract twice. Inputs reachable, bars visible.
Minimal capabilities: storage/export/share/clipboard/haptics/device/documents/photos/audio/browser/maps/phone/email/sms. Documented contracts only: no arbitrary files, clipboard read, direct camera/microphone, location, Bluetooth, notifications, background execution, network or billing. JSON adds no permissions/native code.
Await results; handle rejection. No user/credential logs; preview proves no native effect.
Load `<script src="/factory-sdk.js"></script>` before local JS at https://app.jarvys.invalid. No inline scripts/handlers. Never replace SDK/weaken origin/frame checks.
Frozen window.Jarvys Promises:
- Jarvys.runtime.info(): metadata, no capability grant.
- Jarvys.storage.get(key): string/null; set(key,value): string storage; remove(key): delete; list(): keys. Serialize structures.
- Jarvys.export.text({filename,text,mimeType}): export. Optional MIME: text/plain, text/markdown, application/json, text/csv. {saved:true} confirms saving; cancellation rejects.
- Jarvys.share.text({text,title}): chooser, optional title; {chooserOpened:true} proves no receipt/sending.
- Jarvys.clipboard.write(text): native confirmation; no read API.
- Jarvys.haptics.perform(kind): tap/longPress; returns whether performed.
- Jarvys.device.info(): platform/apiLevel/appId/targetSdk; no stable personal IDs.
Except runtime.info, declare capabilities. Show failures; never weaken security.
Version storage; handle missing/invalid data/upgrades. Never clear on startup or report failed saves as success. User-initiated export/share; cancellation is not delivery.
## Documents (v67)
SDK 2 Jarvys.documents requires documents. open({mimeType}) resolves {handle,mode:"read",expiresAfterMs:300000,maximumBytes:16777216,providerCommitConfirmed:false}; create({filename,mimeType}) returns same with mode:"write". Required MIME: <=127 chars, one type, no parameters; open allows */* or image/*; create concrete only. filename: [a-zA-Z0-9][a-zA-Z0-9 _.-]{0,119}; no .. or final dot.
read({handle,offset,length}) returns {data,offset,nextOffset,eof}; write({handle,offset,data}) returns {offset,nextOffset,bytesWritten,providerCommitConfirmed:false}. data: canonical padded standard base64, no data URL; decoded chunks/length 1..32768 bytes. Integer offset starts 0; use nextOffset sequentially, no parallel/seek. EOF data may be empty; short read alone is not EOF. close({handle}) returns {status:"close_requested",providerCommitConfirmed:false}; cancel() or cancel({}) returns {cancelled:true,rollbackConfirmed:false,pickerMayRemainOpen}.
Read: open, read sequentially to eof/quota, then close. Shrink chunks to remaining quota. Write sequentially; close in finally; show failures.
Limits: 16 MiB/handle, 32 MiB cumulative/page-session, four slots including cleanup, five-minute expiry. Cancel (native cancelAll) and close preserve quota. No paths/URIs/persistent grants/saved handles. Background/reset/rotation revokes handles. Installed: one selection at a time; opening next closes previous. BUSY may persist across instances during provider cleanup. Handle errors: INVALID_HANDLE, WRONG_MODE, HANDLE_BUSY, INVALID_OFFSET, INVALID_CHUNK, DOCUMENT_QUOTA, HANDLE_LIMIT, SESSION_REVOKED, DOCUMENT_IO. Also INVALID_ARGUMENT/INVALID_REQUEST, CAPABILITY_DENIED, UNAVAILABLE, BUSY, CANCELLED, PERMISSION_DENIED, RATE_LIMITED, TIMEOUT, NATIVE_ERROR. Never blindly retry writes.
Install compatible build-pinned Jarvys. Its native broker verifies caller certificate/hash/version against exact latest signed identity/scope; both host packages installed blocks access. Signing newer blocks prior installed releases until updated to that exact APK. Human review, Android picker and Use this document mandatory; never automate. Automation stays blocked. Settings → Factory documents recovery: human acknowledges old picker/task closure; user-reported, not OS proof. Outcome unknown; no restored authority.
Cancel cannot roll back writes; create may leave empty/partial files without handles. Cloud providers may transfer remotely. close_requested proves no durable commit/upload. Other F1/F2/F3 families stay closed; physical acceptance remains pending.
Jarvys.share.file({handle,filename,mimeType}) requires documents+share and an untouched read handle. Consumes a complete 1-byte–8 MiB snapshot against existing quotas; reopen after failure. No raw bytes/URI/path/target. Same concrete MIME/simple filename rules. Pinned authenticated host stages 32 KiB chunks; human-only review opens chooser. Five-minute expiry; native close/recovery keeps automation blocked until acknowledgment of closing the chooser/recipient task. {chooserOpened,deliveryConfirmed:false} never proves delivery. Cancel/expiry cannot recall copies/open descriptors; recipients may upload. Preview is unavailable.
## Photos (v69)
Jarvys.photos.pick({}) / capture({}): photos+documents, same exact-latest authenticated host. Human launch/Use only; never automate. Return opaque read handles for documents.read/close/share.file; 8 MiB JPEG/PNG, <=4096 per side/12 MP, five minutes. Snapshot acquisition also charges cumulative quota. Original metadata, including location, stays intact. Camera: one write-only bounded pipe; seeking/reopen fails, never thumbnail fallback. No gallery save/autosend; camera may retain copies. Preview unavailable. Close interrupted UI yourself; Settings → Factory photos recovery. API24–29: provider FDs must be regular.
Jarvys.audio.play({handle}): audio+documents; consumes untouched read handle (6 MiB, charged EOF/quota). Canonical 44-byte-header PCM16 WAV only: mono/stereo, 8–48 kHz, whole frames, <=30 s. Host reviews bytes; human Play once with current output/volume. No URI/path/codec/TTS/network engine/looping/resume/background audio. Native Close/recovery guards automation; focus/lifecycle/route loss stops. documents.cancel requests revocation, not confirmed stop. {playbackAttempted,audibilityConfirmed:false} never proves hearing. Document selection may use cloud providers. Preview unavailable.
## Browser (v71)
Jarvys.browser.open({url}): browser only, pinned authenticated host; no documents grant. Exact ASCII URL <=2048: lowercase https, lowercase DNS host (>=2 labels, <=63/label, <=253 total), optional :443. No userinfo/fragment, local/numeric host, trailing dot, controls, whitespace, backslash or malformed escapes; escaped controls/space/DEL/backslash also fail. No normalization or secret detection: never include passwords/tokens. Human-only full URL/host/browser review; never automate. URL/path/query reaches browser/site; cookies/accounts/history/sync may apply. DNS/redirects/resources may reach other destinations/HTTP/apps outside Jarvys control. No Jarvys fetch/generated Internet permission. Durable one-shot guard, five minutes, no retries. Manually close browser then review, or Settings → Factory browser recovery. Cancellation cannot retract/close/undo. {launchRequested,pageLoadConfirmed:false} means only dispatch acceptance, never rendered page/delivery. Preview unavailable; documents.cancel is unrelated. TTS/voice remain unsupported.
## Maps/dialer (v72)
Jarvys.maps.open({latitude,longitude}) requires maps: finite numbers [-90,90]/[-180,180], canonical plain decimals. Or open({query}): nonblank paired Unicode, 1–256 codepoints/1024 UTF8 bytes, no control/format/line/paragraph characters; encoded once. Jarvys.phone.dial({number}) requires phone: optional + and 1–15 ASCII digits unchanged; no USSD/extensions. Exact keys only. Both need pinned host, no documents grant. Human-only full data/recipient review; never automate. Only geo ACTION_VIEW/tel ACTION_DIAL; no GPS/autocall/arbitrary URI/intent. Recipients may use network/accounts/history/permissions outside Jarvys control. Separate durable guard/five minutes/no replay; close external task then native review or Settings → External action review. Closure is user-reported, not OS-verified. {launchRequested,actionConfirmed:false} proves only dispatch, not display/navigation/call/delivery. Preview unavailable; documents.cancel unrelated.

## Build/sign
1. Read back spec/sources; check references/offline dependencies/branding/JS/escaping/capabilities. Inspection is not execution.
2. `build`: spec_path, output_path, fresh expected_scope_version; new relative output. No per-app Java/Kotlin compilation. Retain path/hash/app/version/template.
3. After error/interruption/conflict reread state; never replay writes/overwrite outputs. Retain uncertainty; use fresh outputs. Filenames prove no build/installability.
4. `sign`: input_path, exact expected_sha256, distinct output_path, current expected_scope_version. Same-project receipt/in-app approval; never bypass/export keys/use debug keys/replace identity.
5. Existing non-exportable AndroidKeyStore keys cannot be backed up/converted; losing them may prevent updates. Source/APK backups do not restore keys.
6. Report exact artifact/verification. No step here installs the APK. Install/coexistence/update/data retention need Android evidence.
