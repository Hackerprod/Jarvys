## Contract

Clarify audience/workflows/style/identity/data/features. New app: unique ID/name/icon. Update: same appId/key, higher versionCode; preserve unrelated apps. Await/catch results; no user/credential logs or preview native-effect claims.
Load `<script src="/factory-sdk.js"></script>` before local JS at https://app.jarvys.invalid. No inline scripts/handlers. Never replace SDK/weaken origin/frame checks.
window.Jarvys frozen Promises:
- Jarvys.runtime.info(): metadata, no capability grant.
- Jarvys.storage.get(key): string/null; set(key,value): string storage; remove(key): delete; list(): keys. Serialize structures.
- Jarvys.export.text({filename,text,mimeType}): export. Optional MIME: text/plain, text/markdown, application/json, text/csv. {saved:true} confirms saving; cancellation rejects.

Declare capabilities except runtime.info; show failures, preserve security.
Version storage; handle missing/invalid/upgraded data. Never clear at startup or claim failed saves succeed. Human-initiated export/share; cancellation is not delivery.
## Documents (v67)
SDK 2 Jarvys.documents requires documents. open({mimeType}) resolves {handle,mode:"read",expiresAfterMs:300000,maximumBytes:16777216,providerCommitConfirmed:false}; create({filename,mimeType}) returns same with mode:"write". Required MIME: <=127 chars, one type, no parameters; open allows */* or image/*; create concrete only. filename: [a-zA-Z0-9][a-zA-Z0-9 _.-]{0,119}; no .. or final dot.
read({handle,offset,length}) returns {data,offset,nextOffset,eof}; write({handle,offset,data}) returns {offset,nextOffset,bytesWritten,providerCommitConfirmed:false}. data: canonical padded standard base64, no data URL; decoded chunks/length 1..32768 bytes. Integer offset starts 0; use nextOffset sequentially, no parallel/seek. EOF data may be empty; short read alone is not EOF. close({handle}) returns {status:"close_requested",providerCommitConfirmed:false}; cancel() or cancel({}) returns {cancelled:true,rollbackConfirmed:false,pickerMayRemainOpen}.
Read sequentially to EOF/quota; shrink chunks to quota. Write sequentially; always close in finally/show failures.
Limits: 16 MiB/handle, 32 MiB cumulative/page-session, four slots including cleanup, five-minute expiry. Cancel (native cancelAll) and close preserve quota. No paths/URIs/persistent grants/saved handles. Background/reset/rotation revokes handles. Installed: one selection at a time; opening next closes previous. BUSY may persist across instances during provider cleanup. Handle errors: INVALID_HANDLE, WRONG_MODE, HANDLE_BUSY, INVALID_OFFSET, INVALID_CHUNK, DOCUMENT_QUOTA, HANDLE_LIMIT, SESSION_REVOKED, DOCUMENT_IO. Also INVALID_ARGUMENT/INVALID_REQUEST, CAPABILITY_DENIED, UNAVAILABLE, BUSY, CANCELLED, PERMISSION_DENIED, RATE_LIMITED, TIMEOUT, NATIVE_ERROR. Never blindly retry writes.
Require pinned Jarvys; broker checks caller certificate/hash/version against latest signed identity/scope. Both hosts installed blocks access. Signing newer requires updating to that exact APK. Human review/picker/Use this document required; never automate; guard stays active. Settings → Factory documents recovery: human acknowledges old picker/task closure; user-reported, not OS proof. Outcome unknown; no restored authority.
Cancel cannot undo writes; create may leave empty/partial files. Providers may transfer remotely. close_requested proves no commit/upload. Remaining F1/F2/F3 closed; physical acceptance pending.
Jarvys.share.file({handle,filename,mimeType}) requires documents+share and an untouched read handle. Consumes a complete 1-byte–8 MiB snapshot against existing quotas; reopen after failure. No raw bytes/URI/path/target. Same concrete MIME/simple filename rules. Pinned authenticated host stages 32 KiB chunks; human-only review opens chooser. Five minutes; native close/recovery guards automation until acknowledgment of chooser/recipient closure. {chooserOpened,deliveryConfirmed:false} never proves delivery. Cancel/expiry cannot recall copies/open descriptors; recipients may upload.

Native Close/recovery guards automation; focus/lifecycle/route loss stops. documents.cancel requests revocation, not confirmed stop. {playbackAttempted,audibilityConfirmed:false} never proves hearing. Document selection may use cloud providers.
## Browser (v71)
Jarvys.browser.open({url}): browser only, pinned authenticated host; no documents grant. Exact ASCII URL <=2048: lowercase https, lowercase DNS host (>=2 labels, <=63/label, <=253 total), optional :443. No userinfo/fragment, local/numeric host, trailing dot, controls, whitespace, backslash or malformed escapes; escaped controls/space/DEL/backslash also fail. No normalization/secret detection; never include passwords/tokens. Human-only full URL/host/browser review; never automate. URL/path/query reaches browser/site; cookies/accounts/history/sync may apply. DNS/redirects/resources may reach other destinations/HTTP/apps outside Jarvys control. No Jarvys fetch/generated Internet permission. Durable one-shot guard, five minutes, no retries. Manually close browser then review, or Settings → Factory browser recovery. Cancellation cannot retract/close/undo. {launchRequested,pageLoadConfirmed:false} means only dispatch acceptance, never rendered page/delivery. Preview unavailable; documents.cancel is unrelated.
## Maps/dialer (v72)

Or open({query}): nonblank paired Unicode, 1–256 codepoints/1024 UTF8 bytes, no control/format/line/paragraph characters; encoded once. Jarvys.phone.dial({number}) requires phone: optional + and 1–15 ASCII digits unchanged; no USSD/extensions. Exact keys only. Both need pinned host, no documents grant. Human-only full data/recipient review; never automate. Only geo ACTION_VIEW/tel ACTION_DIAL; no GPS/autocall/arbitrary URI/intent. Recipients may use network/accounts/history/permissions outside Jarvys control. Separate durable guard/five minutes/no replay; close external task then native review or Settings → External action review. Closure is user-reported, not OS-verified. {launchRequested,actionConfirmed:false} proves only dispatch, not display/navigation/call/delivery. Preview unavailable; documents.cancel unrelated.
