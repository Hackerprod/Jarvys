# APK Factory
Factory API26+/apps API24+.
## Contract
Inspect schema/capabilities/limits/template with `apk_factory inspect`; availability governs. Read scope/files; relative paths and Captain-reviewed external adoption. Clarify audience/workflows/style/identity/data. New app: unique ID/name/icon; update: same appId/key, higher versionCode. Preserve other apps. Web/spec cannot extend DEX, libraries, permissions, services or APIs; unsupported features need template review.

Responsive/scrollable forms with viewport meta. Native owns bar/cutout/keyboard insets: no double subtraction; inputs reachable/bars visible.
Capabilities: storage/export/share/clipboard/haptics/device/documents/photos/audio/browser/maps/phone/email/sms/contacts/calendar. Contracts only: no arbitrary files/clipboard read/direct camera/microphone/location/Bluetooth/notifications/background/network/billing. JSON adds no permissions/code.
Await/catch; no user/credential logs or preview native-effect claims.
Load `<script src="/factory-sdk.js"></script>` before local JS at https://app.jarvys.invalid. No inline scripts/handlers. Never replace SDK/weaken origin/frame checks.
window.Jarvys frozen Promises:
- Jarvys.runtime.info(): metadata, no capability grant.

## Documents (v67)
SDK 2 Jarvys.documents requires documents. open({mimeType}) resolves {handle,mode:"read",expiresAfterMs:300000,maximumBytes:16777216,providerCommitConfirmed:false}; create({filename,mimeType}) returns same with mode:"write". Required MIME: <=127 chars, one type, no parameters; open allows */* or image/*; create concrete only. filename: [a-zA-Z0-9][a-zA-Z0-9 _.-]{0,119}; no .. or final dot.
read({handle,offset,length}) returns {data,offset,nextOffset,eof}; write({handle,offset,data}) returns {offset,nextOffset,bytesWritten,providerCommitConfirmed:false}. data: canonical padded standard base64, no data URL; decoded chunks/length 1..32768 bytes. Integer offset starts 0; use nextOffset sequentially, no parallel/seek. EOF data may be empty; short read alone is not EOF. close({handle}) returns {status:"close_requested",providerCommitConfirmed:false}; cancel() or cancel({}) returns {cancelled:true,rollbackConfirmed:false,pickerMayRemainOpen}.
Read sequentially to EOF/quota; shrink chunks to quota. Write sequentially; always close in finally/show failures.
Limits: 16MiB/handle, 32MiB/page-session, four slots incl cleanup, five minutes. Cancel/close preserve quotas. No paths/URIs/persistent grants/saved handles. Background/reset/rotation revoke; one installed selection, next closes prior. BUSY can outlive instances during cleanup. Display handle/mode/offset/chunk/quota/session/I/O and general errors exactly; never blindly retry writes.
Pinned Jarvys verifies latest signed caller certificate/hash/version/scope; both hosts installed blocks access. Update to exact latest signed APK. Human review/picker/Use required; never automate. Settings → Factory documents recovery requires human-declared old task closure, not OS proof or restored authority.
Cancel cannot undo writes; create may leave empty/partial files. Providers may transfer remotely. close_requested proves no commit/upload. Remaining F1/F2/F3 closed; physical acceptance pending.
Jarvys.share.file({handle,filename,mimeType}) requires documents+share and an untouched read handle. Consumes a complete 1-byte–8 MiB snapshot against existing quotas; reopen after failure. No raw bytes/URI/path/target. Same concrete MIME/simple filename rules. Pinned authenticated host stages 32 KiB chunks; human-only review opens chooser. Five minutes; native close/recovery guards automation until acknowledgment of chooser/recipient closure. {chooserOpened,deliveryConfirmed:false} never proves delivery. Cancel/expiry cannot recall copies/open descriptors; recipients may upload.
## Photos (v69)

Return opaque read handles for documents.read/close/share.file; 8 MiB JPEG/PNG, <=4096 per side/12 MP, five minutes. Snapshot acquisition also charges cumulative quota. Original metadata/location retained. Camera: one write-only bounded pipe; seeking/reopen fails, never thumbnail fallback. No gallery save/send; camera may retain copies. Jarvys.audio.play({handle}): audio+documents; consumes untouched read handle (6 MiB, charged EOF/quota). Canonical 44-byte-header PCM16 WAV only: mono/stereo, 8–48 kHz, whole frames, <=30 s. Host reviews bytes; human Play once with current output/volume. No URI/path/codec/TTS/network/loop/resume/background audio. Native Close/recovery guards automation; focus/lifecycle/route loss stops. documents.cancel requests revocation, not confirmed stop. {playbackAttempted,audibilityConfirmed:false} never proves hearing. Document selection may use cloud providers.
## Browser (v71)
Jarvys.browser.open({url}): browser only, pinned authenticated host; no documents grant. Exact ASCII URL <=2048: lowercase https, lowercase DNS host (>=2 labels, <=63/label, <=253 total), optional :443. No userinfo/fragment, local/numeric host, trailing dot, controls, whitespace, backslash or malformed escapes; escaped controls/space/DEL/backslash also fail. No normalization/secret detection; never include passwords/tokens. Human-only complete URL/host/browser review; never automate. URL/path/query reaches browser/site; cookies/accounts/history/sync apply. DNS/redirects/resources can reach other destinations/HTTP/apps; Jarvys cannot control them. No Jarvys fetch/generated Internet permission. Durable five-minute one-shot guard/no retries. Close browser, then native review/Settings recovery. Cancel cannot retract/close/undo. {launchRequested,pageLoadConfirmed:false}: dispatch only, not rendering/delivery. Preview unavailable; documents.cancel unrelated.
## Maps/dialer (v72)
Jarvys.maps.open({latitude,longitude}) requires maps: finite numbers [-90,90]/[-180,180], canonical plain decimals. Or open({query}): nonblank paired Unicode, 1–256 codepoints/1024 UTF8 bytes, no control/format/line/paragraph characters; encoded once. Jarvys.phone.dial({number}) requires phone: optional + and 1–15 ASCII digits unchanged; no USSD/extensions. Exact keys only. Both need pinned host, no documents grant. Human-only full data/recipient review; never automate. Only geo ACTION_VIEW/tel ACTION_DIAL; no GPS/autocall/arbitrary URI/intent. Recipients may use network/accounts/history/permissions outside Jarvys control. Separate durable guard/five minutes/no replay; close external task then native review or Settings → External action review. Closure is user-reported, not OS-verified. {launchRequested,actionConfirmed:false} proves only dispatch, not display/navigation/call/delivery. Preview unavailable; documents.cancel unrelated.

## Build/sign
Read back spec/sources; verify references/offline dependencies/branding/JS/escaping/capabilities. Inspection is not execution.
`build`: spec_path, fresh expected_scope_version, new relative output_path. No per-app compile; retain path/hash/app/version/template.

Report artifact/checks; no implicit installation.
