# Factory guidance factory-guidance-v78 / documents-media

Use with the always-loaded Factory core; this reference grants no tools or approvals.

## Documents (v67)
Jarvys.documents needs documents. open({mimeType}): {handle,mode:"read",expiresAfterMs:300000,maximumBytes:16777216,providerCommitConfirmed:false}; create({filename,mimeType}): same, mode:"write". MIME required: <=127 chars, one type/no parameters; open */* or image/* allowed, create concrete. filename: [a-zA-Z0-9][a-zA-Z0-9 _.-]{0,119}; no .. or final dot.
read({handle,offset,length}): {data,offset,nextOffset,eof}; write({handle,offset,data}): {offset,nextOffset,bytesWritten,providerCommitConfirmed:false}. data: canonical padded standard base64, no data URL; decoded chunks/length1..32768 bytes. Integer offset0 then nextOffset; no parallel/seek. EOF data may be empty; short read≠EOF. close({handle}): {status:"close_requested",providerCommitConfirmed:false}; cancel()/cancel({}): {cancelled:true,rollbackConfirmed:false,pickerMayRemainOpen}.
Read to EOF/quota; shrink chunks to quota. Sequential writes; finally close/show failures.
Limits:16MiB/handle,32MiB/page-session,4 slots incl cleanup,5min. Cancel/close retain quotas. No paths/URIs/persistent grants/saved handles. Background/reset/rotation revoke; one installed selection, next closes prior. Cleanup BUSY can outlive instances. Exact handle/mode/offset/chunk/quota/session/I/O/general errors; no blind write retries.
Pinned Jarvys checks exact latest signed caller certificate/hash/version/scope; two installed hosts block. Human review/picker/Use; never automate. Settings → Factory documents recovery: declared old-task closure, no OS proof/restored authority.
Cancel cannot undo writes; create may leave empty/partial files; providers may transfer remotely. close_requested proves no commit/upload.
share.file({handle,filename,mimeType}): documents+share, untouched read handle. Consumes full 1-byte–8MiB snapshot/existing quotas; reopen after failure. No raw bytes/URI/path/target. Same concrete MIME/filename rules. Pinned authenticated host stages 32 KiB chunks; human review opens chooser. 5min; native close/recovery blocks automation until chooser/recipient closure acknowledgment. {chooserOpened,deliveryConfirmed:false} never proves delivery. Cancel/expiry cannot recall copies/FDs; recipients may upload.
## Photos (v69)
photos.pick({})/capture({}): photos+documents, same authenticated host. Human-only launch/Use; never automate. Opaque read handles: documents.read/close/share.file; 8 MiB JPEG/PNG, <=4096 per side/12 MP, 5min. Acquisition charges cumulative quota. Metadata/location retained. Camera: bounded write-only pipe; no seeking/reopen/thumbnail fallback. No gallery save/send; camera may retain copies. Close interrupted UI; Settings → Factory photos recovery. API24–29: provider FDs must be regular.
audio.play({handle}): audio+documents; consumes untouched read handle (6 MiB, charged EOF/quota). Only canonical PCM16 WAV/44-byte header: mono/stereo, 8–48 kHz, whole frames, <=30 s. Host byte review; human Play once/current output/volume. No URI/path/codec/TTS/network/loop/resume/background. Native Close/recovery blocks automation; focus/lifecycle/route loss stops. documents.cancel: revocation request, no stop proof. {playbackAttempted,audibilityConfirmed:false}: no hearing proof. Selection may use cloud providers.
