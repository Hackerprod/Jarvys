## Documents (v67)
Jarvys.documents needs documents. open({mimeType}): {handle,mode:"read",expiresAfterMs:300000,maximumBytes:16777216,providerCommitConfirmed:false}; create({filename,mimeType}): same, mode:"write". MIME required: <=127 chars, one type/no parameters; open */* or image/* allowed, create concrete. filename: [a-zA-Z0-9][a-zA-Z0-9 _.-]{0,119}; no .. or final dot.
read({handle,offset,length}): {data,offset,nextOffset,eof}; write({handle,offset,data}): {offset,nextOffset,bytesWritten,providerCommitConfirmed:false}. data: canonical padded standard base64, no data URL; decoded chunks/length1..32768 bytes. Integer offset0 then nextOffset; no parallel/seek. EOF data may be empty; short read≠EOF. close({handle}): {status:"close_requested",providerCommitConfirmed:false}; cancel()/cancel({}): {cancelled:true,rollbackConfirmed:false,pickerMayRemainOpen}.
Read to EOF/quota; shrink chunks to quota. Sequential writes; finally close/show failures.
Limits:16MiB/handle,32MiB/page-session,4 slots incl cleanup,5min. Cancel/close retain quotas. No paths/URIs/persistent grants/saved handles. Background/reset/rotation revoke; one installed selection, next closes prior. Cleanup BUSY can outlive instances. Exact handle/mode/offset/chunk/quota/session/I/O/general errors; no blind write retries.
Pinned Jarvys checks exact latest signed caller certificate/hash/version/scope; two installed hosts block. Saved policy: ALLOW_ALWAYS opens the picker, ASK reviews once before it, DENY blocks. Valid selection returns access without another Use confirmation. Settings → Factory documents recovery reconciles uncertainty, never proves OS closure or restores authority.
Cancel cannot undo writes; create may leave empty/partial files; providers may transfer remotely. close_requested proves no commit/upload.
share.file({handle,filename,mimeType}): documents+share, untouched read handle. Consumes full 1-byte–8MiB snapshot/existing quotas; reopen after failure. No raw bytes/URI/path/target. Same concrete MIME/filename rules. Pinned authenticated host stages 32 KiB chunks; saved policy opens chooser (ASK reviews once). 5min recipient lease; chooser return delivers a dispatch-only receipt without another closure acknowledgment. {chooserOpened,deliveryConfirmed:false} never proves delivery. Cancel/expiry cannot recall copies/FDs; recipients may upload.
## Photos (v69)
photos.pick({})/capture({}): photos+documents, same authenticated host. Saved policy controls launch; ASK reviews once, valid selection has no second Use confirmation. Opaque read handles: documents.read/close/share.file; 8 MiB JPEG/PNG, <=4096 per side/12 MP, 5min. Acquisition charges cumulative quota. Metadata/location retained. Camera: bounded write-only pipe; no seeking/reopen/thumbnail fallback. No gallery save/send; camera may retain copies. Close interrupted UI; Settings → Factory photos recovery. API24–29: provider FDs must be regular.
audio.play({handle}): audio+documents; consumes untouched read handle (6 MiB, charged EOF/quota). Only canonical PCM16 WAV/44-byte header: mono/stereo, 8–48 kHz, whole frames, <=30 s. Host byte validation; ALLOW_ALWAYS plays automatically, ASK reviews once; current output/volume. No URI/path/codec/TTS/network/loop/resume/background. ALLOW_ALWAYS closes after confirmed player cleanup; unknown cleanup still blocks; focus/lifecycle/route loss stops. documents.cancel: revocation request, no stop proof. {playbackAttempted,audibilityConfirmed:false}: no hearing proof. Selection may use cloud providers.

## SQLite backup integration (v83)

Read the database reference for the full backup policy and grammar. database.backupExport({version,tables,filename}) and database.backupImport({version,handle,tables,mode}) require database+documents and a nonempty explicit dataBackup.tables policy; default empty disables them. Import consumes an untouched read handle for canonical plaintext JSON <=1 MiB; export uses its own human-selected write destination. Table selections must be explicit, sorted and unique. These methods carry selected SQLite schemas/rows only, never document contents, preferences or signing keys. Same-package/certificate labels check compatibility, not authenticity. Secrets cannot be detected reliably and are unsupported.

The exact current signed receipt and pinned host must pass verification before applying the saved backup policy; ASK reviews all values once. Export additionally discloses the destination provider and possible cloud sync/retention. ALLOW_ALWAYS continues without host confirmation; Android destination selection remains. No provider or physical durability is proved: providerCommitConfirmed:false, partial files possible. insertOnly rolls back all on any collision; replaceSelectedTables replaces only selected tables atomically, preserving unselected tables. Exact version/schema are required, no migration; changed targets after review fail conflict. Cancel/lost reply may follow commit; no automatic retry. Both backup methods are UNAVAILABLE in preview. Existing documents quotas, handle/session ownership, lifecycle revocation and cleanup rules still apply.

## String key-value backup integration (v84)

Read basics for storage.backupExport({version:1,keys,filename}) and storage.backupImport({version:1,keys,handle,mode}). These require storage+documents and explicit dataBackup.keys; default empty disables them. They carry selected Jarvys.storage strings only, excluding presentation preferences and SQLite. Import consumes an untouched read handle for canonical plaintext JSON <=1 MiB; exact selected keys, saved backup authorization (one all-values review for ASK) and independent signed policy verification are mandatory. No combined SQLite/storage transaction exists. insertOnly rejects even equal-value collisions; replaceSelectedKeys preserves every unselected key. Commit false/exception is unknown, without rollback or replay. documents.cancel cancels storage backups through the authenticated fast path, sharing the native backup control rate budget with database.cancel. Both backup families remain UNAVAILABLE in preview before handles or databases are allocated. Provider/secret/uncertainty disclosures above still apply.
