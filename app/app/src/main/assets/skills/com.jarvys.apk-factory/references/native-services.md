# Factory guidance factory-guidance-v85 / native-services

23 capabilities/59 methods, SDK2/schema1. Source guidance, no validation/authority claim. All methods need declared capability/installed foreground; all reject UNAVAILABLE in preview before effects, including status/cancel. Rebuild old templates with same ID/key and higher version.

## Shared authority and manifest
Read basics: default ALLOW_ALWAYS, ASK once or DENY; real Android grants remain. Exact retained caller scope and live request-bound pinned-host lease cover network requests/probes/ping, notification mutations and speech voices/speak/stop. Status is read-only; network.cancel cleans owned jobs. Lifecycle/policy loss ends pending work; no replay or rollback claim.

Template stays permission-free. Selected network adds INTERNET/usesCleartextTraffic=true; notifications POST_NOTIFICATIONS; biometrics USE_BIOMETRIC. speech adds exact android.intent.action.TTS_SERVICE query alongside two host packages. Export/share/native families need host pin. No broad queries/new service/receiver/compiler. INTERNET is process-wide: WebView/CSP proves no zero egress. Platform TLS/hostname checks remain. TTS/provider/recipient can use its own network without app INTERNET.

Runtime metadata: offline means only configured WebView behavior, not process isolation; offlineScope is embedded_webview_configuration_not_process_isolation. processInternetPermission follows network selection; speechEngineMayUseNetwork:true, nativeProbeIsIcmp:false and nativePingProtocol:"icmp" are disclosures, no permission or test evidence. Pending lease acquisition/ASK expires after 5 min; approved foreground work remains live-checked. SDK waits: native network/notifications and speech status/voices/stop 420000 ms; speak 86400000 ms. A timeout proves no rollback.

## Native HTTP
Jarvys.network.request({url,method?,headers?,body?,bodyBase64?,responseType?,connectTimeoutMs?,readTimeoutMs?,timeoutMs?,maxRequestBytes?,maxResponseBytes?,maxHeaderBytes?,redirect?,maxRedirects?,allowHttpsDowngrade?}). Exact keys/types; absolute HTTP(S) URL ≤8192 UTF-8 bytes, no userinfo/fragment, invalid port, control/space/backslash. Methods are HTTP tokens ≤32 chars, default GET; platform-unsupported methods reject. Choose UTF-8 body or canonical padded bodyBase64, never both; GET/HEAD/TRACE bodies reject. responseType text(default)|base64. No automatic session management.

Defaults/ranges: connectTimeoutMs/readTimeoutMs 10000, timeoutMs 30000; each 1–120000 ms. maxRequestBytes/maxResponseBytes default 65536, range 0–262144. maxHeaderBytes default 16384, range 256–32768. At most 64 request headers; ASCII field values and no case-duplicate or transport-managed headers (Host/Content-Length/Transfer-Encoding/Connection/Proxy-Connection/Expect/Upgrade/Trailer/TE). 512 KiB request envelope; encoded results≤512 KiB minus 4096. Oversize rejects, never silent body truncation.

redirect follow(default)|manual|error; maxRedirects default 5, range 0–10. HTTPS→HTTP requires allowHttpsDowngrade:true (default false) and Android cleartext permission. Cross-origin redirects discard all caller headers; 303 except HEAD and 301/302 POST switch to GET without body. Preserved-method redirects can forward bodies; authorize that. System proxy/DNS/server behavior remains external.

Success returns {url,method,status,ok,headers,redirects,latencyMs,elapsedMs,cleartext,bodyBytes,responseType} plus body/charset or bodyBase64. headers maps lowercase names to arrays. HTTP 4xx/5xx are responses with ok:false; latencyMs measures time through response headers, elapsedMs through read, not ICMP RTT. Transport/protocol/redirect/size errors reject; bytes may already have been sent.

Jarvys.network.probe({url,method?,headers?,connectTimeoutMs?,readTimeoutMs?,timeoutMs?,maxHeaderBytes?,redirect?,maxRedirects?,allowHttpsDowngrade?}) uses HTTP HEAD(default) or GET without consuming a body. Successful response adds measurement:"http_response_headers",icmp:false,reachable:true; HTTP error statuses can still be reachable. I/O failure can return reachable:false,error with elapsedMs; cancellation, deadline/policy and validation errors reject. This is not ping or ICMP.

network.cancel({})/no args cancels owned jobs: {cancelled:<count>,rollbackConfirmed:false}. Socket/DNS teardown may outlast cancellation; bytes/remote work cannot be recalled.

## Real ICMP ping
Jarvys.network.ping({host,family?,count?,timeoutMs?,packetTimeoutMs?,intervalMs?,packetBytes?,maxOutputBytes?}). host is a normalized DNS name/IPv4/IPv6 literal, including validated scoped IPv6; not a URL, shell fragment or executable. family auto(default)|ipv4|ipv6. Integer defaults/ranges: count4/1–1000; timeoutMs10000/100–120000; packetTimeoutMs1000/1000–120000; intervalMs1000/200–60000; packetBytes56/0–65507; maxOutputBytes16384/1024–65536.

Uses fixed /system/bin/ping or /system/bin/ping6 with exact argument-vector values, merged output and LC_ALL=C; never shell execution, caller flags or HTTP fallback. packetTimeoutMs becomes whole-second packetWaitMs: the utility's final-response wait, not a guaranteed per-packet timer. External timeoutMs bounds the operation. OEM flags/payload limits differ; grammar acceptance is no support guarantee. Cancel/deadline destroy process and reject CANCELLED/TIMEOUT; no recall.

Result always includes protocol:"icmp",host,family,status,elapsedMs,exitCode (nullable),packetWaitMs,summaryParsed. Captured output adds output/outputBytes/outputTruncated/replySamplesParsed/oversizedLinesSkipped. Status is ok|no_reply|partial|unparsed|unsupported|platform_denied|dns_error|failed. Recognized summaries alone supply transmitted,received,packetLossPercent,reachable. Recognized valid RTT summary supplies latencyMs:{min,avg,max,deviation?,source:"utility_summary"}. Recognized echoes without summary can report partial/reachable:true; they invent no loss/RTT. Unparsed output proves neither reachability nor latency. Bounded-line parsing continues after explicit output truncation. Physical ICMP unverified.

## Immediate notifications
Jarvys.notifications.status({channelId?}) returns status,available,permission,runtimePermissionRequired,notificationsEnabled,channelsSupported,channelStatus,ready; optional channelId/channelImportance. permission:not_required|not_declared|granted|not_granted; status:ready|unavailable|permission_not_declared|permission_required|app_blocked|channel_missing|channel_blocked. No display/read proof.

channel({id,name,description?,importance?}): id [A-Za-z0-9][A-Za-z0-9_.-]{0,63}, name nonblank≤160 UTF-8 bytes, description≤512. importance low|default|high (default default). Native ID is factory.<id>; API26+ creates only missing channels and preserves existing/user settings. API24/25 returns status:not_required; no simulated channel. channelCreated accompanies API26+ status.

show({id,channelId,title,body,priority?}): integer id1–2147483647, same channel grammar, nonblank title≤240 UTF-8 bytes, body≤4096 (may be empty), priority low|default|high. Valid paired Unicode; title/name no controls, body/description permit LF/TAB. App-scoped tag/id replaces its prior notification. API26+ channel and current OS permission/settings must permit it. Receipt {status:"accepted",id} confirms notify call only. Tap uses an immutable Intent to this app's verified launcher, no arbitrary URL/component/extra/actions.

cancel({id}) requests removal of this app's exact ID: {status:"cancel_requested",id}; no read/closure proof. requestPermission({}) uses the real Android 13+/target 33+ POST_NOTIFICATIONS flow when absent and rereads OS status after callback; Android can suppress the dialog or deny. Earlier APIs need no runtime grant. Factory approval grants no OS permission. Immediate only; no schedule/alarm/reboot/background service/fake timer/delivery guarantee.

## Platform text-to-speech
Jarvys.speech.status({}) discovers installed TTS service packages without engine initialization and reports available,busy,engineInitialized,completedChunks,error/status. Availability proves no usable voice/sound. voices({engine?}) initializes the chosen/default installed engine under live policy; returns sorted voice descriptors {name,language,quality,latency,networkRequired}, totalVoices/truncated. Voice-list data is bounded to 256 KiB; truncation is explicit.

speak({text,language?,engine?,voice?,rate?,pitch?,volume?}) accepts nonblank paired-Unicode text≤262144 UTF-8 bytes (512 KiB whole request). language is a valid BCP47 tag≤64 bytes; engine is a package name≤255; voice≤512. Defaults: platform engine/language/voice, rate/pitch/volume 1. Rate/pitch positive finite positive-float-representable; volume 0–1. Android can reject/fallback; missing voice/language/data errors stay explicit, no download.

One speech operation at a time. Full text is split sequentially at the engine input limit without dividing surrogate pairs, preferably at whitespace; no silent truncation. Initialization timeout 30 s; each chunk deadline 10 min. Authority is checked before initialization/configuration/submission/result and polled during work. Promise completes only after final matching engine callback; receipt status:"completed",submittedChunks,completedChunks,requestedEngine,systemDefaultEngine,selectedVoice? and completionMeans:"engine_reported_completion". It does not prove anyone heard audio. All speech disclosures include networkMayBeUsed:true,engineSelection:"android_preference_may_fallback",audibilityVerified:false; even networkRequired:false is no zero-egress guarantee.

stop({}) requests cleanup of the owned operation, returning status:"stop_requested",cancelled and emittedAudioCannotBeRecalled:true. Pause/session end/revocation triggers best-effort stop/shutdown; output/text already emitted or transmitted cannot be recalled. No microphone, speech recognition, background narration, offline-only engine promise or reusable audio file. Device/OEM/audio/network and final global audit/APK remain unclaimed.
