# Factory guidance factory-guidance-v86 / native-services

Installed declared APIs,UNAVAILABLE in preview. Core identity/live policy/OS permissions apply; old DEX needs same-ID/key higher-version update. Network selection adds INTERNET/usesCleartextTraffic=true; speech adds android.intent.action.TTS_SERVICE query. INTERNET is process-wide; local WebView/CSP is no zero-egress proof. Platform TLS trust/hostname verification remains intact; no custom trust bypass. TTS/providers may use network; runtime.info is configuration,no isolation proof.

## Bounded HTTP and probes
network.request({url,method?,headers?,body?,bodyBase64?,responseType?,connectTimeoutMs?,readTimeoutMs?,timeoutMs?,maxRequestBytes?,maxResponseBytes?,maxHeaderBytes?,redirect?,maxRedirects?,allowHttpsDowngrade?}). URL absolute HTTP(S)≤8192 UTF-8 bytes; no userinfo/fragment/invalid port/control/space/backslash. HTTP token method≤32chars, GET default; unsupported platform methods reject. UTF-8 body or canonical padded bodyBase64, never both; GET/HEAD/TRACE bodies reject. responseType text(default)|base64; no automatic cookies/session management.
Timeout defaults connect/read10000,total30000ms, each1..120000. Request/response bytes default65536,0..262144. Header bound16384,256..32768; max64 request headers, ASCII values, no case duplicates or transport-owned Host/Content-Length/Transfer-Encoding/Connection/Proxy-Connection/Expect/Upgrade/Trailer/TE. Envelope512KiB; encoded result≤512KiB−4096. Oversize rejects, no silent truncation.
Redirect follow(default)|manual|error, maxRedirects5/0..10. Downgrade requires allowHttpsDowngrade:true (default false) plus Android cleartext permission. Cross-origin strips all app headers. 303 except HEAD, or301/302 POST, becomes GET/no body; preserved-method redirects can forward body. DNS/proxy/servers are external.
Result {url,method,status,ok,headers,redirects,latencyMs,elapsedMs,cleartext,bodyBytes,responseType}+body/charset or bodyBase64; lowercase header arrays. HTTP4xx/5xx:ok:false. latencyMs headers,not ICMP. Errors may follow transmission.
network.probe({url,method?,headers?,connectTimeoutMs?,readTimeoutMs?,timeoutMs?,maxHeaderBytes?,redirect?,maxRedirects?,allowHttpsDowngrade?}): HEAD(default)|GET headers only, measurement:"http_response_headers",icmp:false,reachable:true even for HTTP error statuses. I/O can return reachable:false,error/elapsedMs; validation/cancellation/deadline/policy errors reject. No body consumption or ICMP fallback.
network.cancel({}) → {cancelled:<count>,rollbackConfirmed:false}. Own jobs only; DNS/socket teardown may outlast cancel, no recall. SDK420000ms includes ASK.

## Streamed document upload/download
network+documents,existing handle/exact offset/signed budgets/live lease. No hidden picker/path. Potential byte charge reserved before connection;8KiB buffer/backpressure,no full Base64. Blocked provider retains capacity.
network.upload({url,handle,length,offset?,method?,headers?,maxBytes?,timeoutMs?,connectTimeoutMs?,readTimeoutMs?,maxHeaderBytes?,redirect?,maxRedirects?,allowHttpsDowngrade?}): default POST, exact length≥0, no body/bodyBase64. offset defaults0; maxBytes defaults handle cap and bounds length; length+offset must fit handle. Fixed-length source read, no extra EOF probe; short source TRANSFER_SOURCE_EOF. Returns response headers/status, never response body/remote-commit proof. contentSnapshotBound:false. Redirect default error; manual returns first response; follow yields UPLOAD_REDIRECT_NOT_REPLAYABLE after first send without reopening connection. Never automatically replay consumed upload.
network.download({url,handle,offset?,method?,headers?,body?,bodyBase64?,maxRequestBytes?,maxBytes?,timeoutMs?,connectTimeoutMs?,readTimeoutMs?,maxHeaderBytes?,redirect?,maxRedirects?,allowHttpsDowngrade?}): default GET/follow,offset0,maxBytes remaining handle budget; bounded inline request still≤256KiB; response streams into writable handle.4xx/5xx bodies may write with ok:false. Redirects resolved before document writes; normal header/body replay semantics apply. At exactly maxBytes returns complete:false,error:TRANSFER_LIMIT_REACHED,limitReached:true,eofConfirmed:false, without an extra read; set larger cap if EOF proof matters.

Timeouts positive up to signed leaseMs≤24h; actual remaining handle lifetime can end sooner. Success leaves handle open at nextOffset; documents.close owns closure. Metadata: documentBytesRead/documentBytesWritten,confirmedNextOffset,nextOffset(null if cursor uncertain),documentPositionUncertain,requestBytesWritten,requestWriteUncertain,requestMayHaveReachedPeer,responseBytesRead,responseReadUncertain,partialEffectsPossible,complete,eofConfirmed,limitReached,error. Always providerCommitConfirmed:false,remoteCommitConfirmed:false,atomicReplacement:false,rollbackConfirmed:false. Ordinary transfer/provider errors can resolve partial metadata; authority/cancel/deadline reject and suppress late delivery. Cannot restore overwritten target/recall sent bytes.

## Real ICMP
network.ping({host,family?,count?,timeoutMs?,packetTimeoutMs?,intervalMs?,packetBytes?,maxOutputBytes?}). host normalized DNS/IP incl validated scopedIPv6, not URL/shell/executable. family auto|ipv4|ipv6. Defaults/ranges: count4/1..1000,total10000/100..120000ms,packet1000/1000..120000ms,interval1000/200..60000ms,packetBytes56/0..65507,output16384/1024..65536.
Fixed /system/bin/ping or /system/bin/ping6 argument vector, LC_ALL=C, never shell execution/caller flags/HTTP fallback. packetTimeoutMs rounds to whole-second packetWaitMs, utility final-response wait, not guaranteed per-packet timing. OEM support is not guaranteed.
Result protocol:"icmp",host,family,status,elapsedMs,exitCode(nullable),packetWaitMs,summaryParsed; captured output/outputBytes/outputTruncated/replySamplesParsed/oversizedLinesSkipped. status ok|no_reply|partial|unparsed|unsupported|platform_denied|dns_error|failed. Only parsed summary supplies transmitted/received/loss/reachable; valid RTT latencyMs:{min,avg,max,deviation?,source:"utility_summary"}. Echo-only partial may mean reachable:true, no invented loss/RTT. Unparsed proves nothing. Cancel/timeout destroys process and rejects, no recall.

## Platform TTS
speech.status({}) discovers services/busy/state without engine startup; availability is no sound proof. speech.voices({engine?}) initializes chosen/default installed engine under live policy; sorted {name,language,quality,latency,networkRequired},totalVoices,truncated,≤256KiB list.
speech.speak({text,language?,engine?,voice?,rate?,pitch?,volume?}): nonblank paired text≤262144 UTF-8bytes/512KiB request; language BCP47≤64bytes,engine package≤255,voice≤512; rate/pitch positive finite float-representable,volume0..1,all default1. Android may reject/fallback; missing data not auto-downloaded. One operation; sequential chunks at engine input bound, never splitting surrogate pairs/truncating. Startup30s/chunk10min. Result after final callback: status:completed,submittedChunks,completedChunks,requestedEngine,systemDefaultEngine,selectedVoice?,completionMeans:"engine_reported_completion". No proof of hearing.
Disclosures networkMayBeUsed:true,engineSelection:"android_preference_may_fallback",audibilityVerified:false; networkRequired:false is no offline guarantee. speech.stop({}) → status:stop_requested,cancelled,emittedAudioCannotBeRecalled:true. Pause/revocation requests stop/shutdown. No background narration/reusable audio file; recording/recognition separate. SDK420000ms,speak86400000ms.

Remote LLM services can compose bounded JSON HTTP with scoped secrets.request. Document streaming supplies no incremental JS SSE/token callback API. No native LLM engine/model weights/tool agent is implied. Local inference needs a separate reviewed engine/model/license/ABI/device decision and runtime implementation.
