# Factory guidance factory-guidance-v78 / external-actions

Use with the always-loaded Factory core; this reference grants no tools or approvals.

## External v71–v75
Named grants + authenticated pinned host/latest signed APK/recipient checks; no documents grant. Human-only full labelled data/recipient review; never automate. 5min durable guards/no replay; cancel cannot recall data/close tasks. Close external task then native/Settings acknowledgment; declared closure, not OS-verified. documents.cancel is unrelated. Preview UNAVAILABLE; physical/OEM unproven. v72–v75 receipts {launchRequested,actionConfirmed:false} prove only dispatch, not display/navigation/call/draft/event creation/saving/sending/delivery. Contacts: approved datum only.
## Browser (v71)
browser.open({url}): browser only. ASCII URL<=2048: lowercase https/DNS host (>=2 labels, <=63/label, <=253 total), optional :443. Reject userinfo/fragment/local/numeric host/trailing dot/controls/whitespace/backslash/malformed escapes, including escaped controls/space/DEL/backslash. No normalization/secret detection/passwords/tokens. Review full URL/host/browser. URL/path/query reaches browser/site; cookies/accounts/history/sync apply. DNS/redirects/resources may reach other destinations/HTTP/apps outside Jarvys control. No Jarvys fetch/Internet permission. One-shot/no retries; close browser then native review/Settings recovery. {launchRequested,pageLoadConfirmed:false}: dispatch only, not rendering/delivery.
## Maps/dialer (v72)
maps.open({latitude,longitude}): maps; finite numbers [-90,90]/[-180,180], canonical plain decimals. Or open({query}): nonblank paired Unicode, 1–256 codepoints/1024 UTF8, no control/format/line/paragraph characters; encoded once. phone.dial({number}): phone; optional +,1–15 unchanged ASCII digits; no USSD/extensions. Exact keys. Only geo ACTION_VIEW/tel ACTION_DIAL; no GPS/autocall/arbitrary URI/intent. Recipient network/accounts/history/permissions: outside Jarvys control. Separate guard; Settings → External action review.
## Editors (v73)
email.compose({to,subject,body}): email only; sms.compose({number,body}): sms only. Strings required; subject/body may be empty. One ASCII email <=254 chars: local <=64 matching [A-Za-z0-9_+\-]+(\.[A-Za-z0-9_+\-]+)*; domain >=2 labels, <=253 total, 1–63 chars/label, letters/digits/hyphens, alphanumeric ends. SMS: same optional +/1–15 ASCII digits. No normalization/existence proof. Subject<=256 codepoints/1024 UTF8; body<=4096 bytes. Paired Unicode; reject ISO/format/bidi/line/paragraph controls except body LF/TAB; no CR. JSON: editors<=32KiB; maps/dialer<=8KiB.
v72 checks/recovery apply. FLAG_SECURE/no saved state/autofill descendants/content capture. ACTION_SENDTO mailto/smsto only; encode local once (+ as %2B), fixed EXTRA_SUBJECT/EXTRA_TEXT or sms_body. No URI queries/arbitrary extras/CC/BCC/attachments/contacts read/permissions/autosend. Opening shares fields; app may ignore/change/cloud-sync/transmit. No secrets; inspect editor yourself. runtime.info: limits/requirements. Zero permissions/two host queries. TTS/voice/F1 and F2/F3 remain pending and unavailable, UX34 gated, UX44 doc-only future defaults, UX43 last.
