# Factory guidance factory-guidance-v86 / lifecycle

## Spec and packaging
factory.json exact required schemaVersion:1,appId,name,positive versionCode,versionName,supported capabilities,relative webDir/icon; web entry index.html. Optional dataBackup,resourceBudgets,incomingShare,notifications,bluetooth,adaptiveIcon are closed schemas. Inspect limits; runtime config/host pin/SDK/DEX/manifest remain factory-owned.
Legacy icon stays required relative.png/.json. Geometry JSON schemaVersion1,opaque #RRGGBB background/fills,1..32 shapes,coordinates0..192:circle{type,cx,cy,r,fill},rect{type,x,y,width,height,fill},polygon{type,points,fill} with3..32[x,y]. Verify files/pixels, never invent images.
Optional adaptiveIcon:{foreground,background,insetPercent?}: foreground relative.png/.json,background #RRGGBB,inset integer0..40 default0. PNG48..1024px/side≤1MiB; foreground JSON≤16KiB exactly{schemaVersion:1,shapes:[...]} (transparent/no background,existing geometry). Fixed192×192RGBA layer,non-square PNG aspect-fit centered; inset20 leaves central60%. Precompiled anydpi-v26 adaptive XML/fixed drawable slots; API24/25 legacy fallback,API26+ adaptive. No per-app XML/compiler/native capability. Launcher acceptance unverified.

Read back/validate spec/assets/JS/capabilities; preserve unrelated edits. build(spec_path,expected_scope_version,new relative output_path): exact scope, precompiled template packaging, retain hash/app/version/template receipt. sign(input_path,expected_sha256,distinct output_path,expected_scope_version): same-project receipt+factory.sign policy (ALLOW_ALWAYS/ASK/DENY), no duplicate prompt. Reconcile state/receipts after errors; no replay/overwrite or filename-based success.
Signed resourceBudgets.packaging defaults/maxima: sourceFiles128/512,singleSourceBytes1MiB/16MiB,totalSourceBytes8MiB/32MiB,apkBytes32MiB/32MiB. Whole APK still≤512ZIP entries including runtime/config/provenance,≤16MiB/entry,≤32MiB expanded/output including overhead; maxima cannot all be used simultaneously. Relative nonhidden source paths≤240chars; traversal≤sourceFiles*120 entries including empty directories. Process-local packaging gate fails busy for overlap; admission uses actual input sizes+16MiB headroom,may reject below maxima,no heap guarantee. Larger archives need separate file-backed build/verifier/sign redesign.

## Identity and keys
New app unique appId/name/icon; update same appId/key and higher versionCode. No silent identity replacement/debug key/tool key export. Legacy AndroidKeyStore keys are non-exportable; loss may block updates. Native Factory identities support passphrase-encrypted export/import, never passphrases/keys in chat/tools/projects/JS/logs. Source/APK backups restore no keys.
Import verifies encryption/key/certificate/appId and merges max version floors; unknown history needs native floor review. Old backups omit newer receipts. Key/project/data backups separate; export proves no restore/update/data-retention acceptance.

## Preview and tests
preview/preview_status/test need exact input_path,expected_sha256,expected_scope_version/current same-project build. Isolated local WebView/storage,simulated export/share/clipboard/haptics; clipboard performed:false. Database preview RAM lost on close/reset/pause. Other native methods UNAVAILABLE before effects,including status/cancel; no fake measurements. Runs under Jarvys,cleanup best effort,no process-isolation/zero-egress proof.
Shared tests run no project JS/device. Current integration awaits final packaged validation and physical/ARM64/update/restore acceptance; report source/synthetic evidence distinctly and honor mission sequencing.

## Installation and delivery
Only requested install, exact signed receipt/hash/scope/app/version/certificate, factory.install policy then Android consent. No duplicate host prompt; signing alone does not request install. Never automate unknown-source grants/security warnings or retry uncertain commit. Play install unavailable. install_status/install_cancel require same exact fields,no APK bytes. Background revokes uncommitted approval; restart never replays.
Only authenticated system success proves install, not retention; missing sessions/UI/postcommit cancel proves no rollback. Missing permission needs manual Android grant+fresh request. Recovery preserves unknown outcome, no global automation lock/data/key erase. Return verified refs/signatures/checks/blockers; printed path is not delivery/publication. Preserve remote history; inspect remote state before authorized push retry.
