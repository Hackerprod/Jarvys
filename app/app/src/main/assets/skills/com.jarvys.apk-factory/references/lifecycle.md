# Factory guidance factory-guidance-v89 / lifecycle

## Spec and packaging
factory.json requires schemaVersion:1,appId,name,positive versionCode,versionName,relative webDir/icon; `capabilities` is optional (omit = all compiled; array = subset). Generated schema1 `factory-app.json` records the effective list, so existing explicit subsets retain their scope. Optional dataBackup,resourceBudgets,incomingShare,notifications,bluetooth,adaptiveIcon are closed schemas. Inspect limits; runtime config/host pin/SDK/DEX/manifest remain factory-owned.
Omission selects all catalog manifest effects: USE_BIOMETRIC, INTERNET/cleartext, POST_NOTIFICATIONS, coarse/fine location, RECORD_AUDIO, ACTIVITY_RECOGNITION, HIGH_SAMPLING_RATE_SENSORS, NFC/optional feature, BLUETOOTH/ADMIN/SCAN/CONNECT plus BLE feature, ACCESS_NETWORK_STATE, RECEIVE_BOOT_COMPLETED, package queries `com.jarvys.agent` and `com.jarvys.agent.recoverytest`, and TTS_SERVICE/RECOGNIZE_SPEECH intent queries. Defaults: incomingShare `*/*`/multiple; Bluetooth scanPrivacy full. Manifest entries do not grant Android runtime permissions. INTERNET is process-wide; subsets narrow scope.
Omission also includes the generic widget provider/action receiver, so the app appears as a widget source in launchers that expose the widget picker; pinning and placement remain launcher-controlled.
Legacy icon stays required relative.png/.json. Geometry JSON schemaVersion1,opaque #RRGGBB background/fills,1..32 shapes,coordinates0..192:circle{type,cx,cy,r,fill},rect{type,x,y,width,height,fill},polygon{type,points,fill} with3..32[x,y]. Verify files/pixels, never invent images.
Optional adaptiveIcon:{foreground,background,insetPercent?}: foreground relative.png/.json,background #RRGGBB,inset integer0..40 default0. PNG48..1024px/side≤1MiB; foreground JSON≤16KiB exactly{schemaVersion:1,shapes:[...]} (transparent/no background,existing geometry). Fixed192×192RGBA layer,non-square PNG aspect-fit centered; inset20 leaves central60%. Precompiled anydpi-v26 adaptive XML/fixed drawable slots; API24/25 legacy fallback,API26+ adaptive. No per-app XML/compiler/native capability. Launcher acceptance unverified.

Read back/validate spec/assets/JS/capabilities; preserve unrelated edits. build(spec_path,expected_scope_version,new relative output_path): exact scope, precompiled template packaging, retain hash/app/version/template receipt. sign(input_path,expected_sha256,distinct output_path,expected_scope_version): same-project receipt and authenticated caller/source, with a per-app Android Keystore identity created automatically on first signing. Reconcile state/receipts after errors; no replay/overwrite or filename-based success.
Signed resourceBudgets.packaging defaults/maxima: sourceFiles128/512,singleSourceBytes1MiB/16MiB,totalSourceBytes8MiB/32MiB,apkBytes32MiB/32MiB. Whole APK still≤512ZIP entries including runtime/config/provenance,≤16MiB/entry,≤32MiB expanded/output including overhead; maxima cannot all be used simultaneously. Relative nonhidden source paths≤240chars; traversal≤sourceFiles*120 entries including empty directories. Process-local packaging gate fails busy for overlap; admission uses actual input sizes+16MiB headroom,may reject below maxima,no heap guarantee. Larger archives need separate file-backed build/verifier/sign redesign.

## Identity and keys
New app unique appId/name/icon; update same appId/key and higher versionCode. Each app gets a non-exportable AndroidKeyStore RSA signing key automatically on its first signature; key loss may block updates. No debug signing keys are provided. There is no signing-key export/import. Source/APK/data backups do not restore signing keys.

## Preview and tests
preview/preview_status/test need exact input_path,expected_sha256,expected_scope_version/current same-project build. Isolated local WebView/storage,simulated export/share/clipboard/haptics; clipboard performed:false. Database preview RAM lost on close/reset/pause. Other native methods UNAVAILABLE before effects,including status/cancel; no fake measurements. Runs under Jarvys,cleanup best effort,no process-isolation/zero-egress proof.
These results default to compact state/counts with failed checks and relevant warnings in detail; test still executes every compiled method and shared validator.
Shared tests run no project JS/device. Current integration awaits final packaged validation and physical/ARM64/update/restore acceptance; report source/synthetic evidence distinctly and honor mission sequencing.

## Installation and delivery
factory.install submits the exact signed receipt/hash/scope/app/version/certificate to Android PackageInstaller. Android may require the user to enable Jarvys as an unknown-source installer and confirm installation. Signing alone does not request installation. Never automate Android security screens or retry an uncertain commit. Play install unavailable. install_status/install_cancel require the same exact fields,no APK bytes. An interrupted pending install session is closed automatically before a new install begins; restart never replays it.
Only authenticated system success proves installation, not retention; missing sessions/UI/postcommit cancel proves no rollback. Interrupted interactions are closed automatically; uncertain effects are not replayed. Return verified refs/signatures/checks/blockers; printed path is not delivery/publication. Preserve remote history; inspect remote state before authorized push retry.
